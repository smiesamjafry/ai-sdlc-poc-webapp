Sample static React shop used as the target repository for the
[ASDLC](https://github.com/smiesamjafry/ai-sdlc) Slack-to-PR proof of concept.

- Pull request previews: `https://smiesamjafry.github.io/ai-sdlc-poc-webapp/pr-preview/pr-<N>/`.
